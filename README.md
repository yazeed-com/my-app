# دردشة — خادم المراسلة

## تشغيل محلي
    npm install
    npm start        # http://localhost:3000

## نشر عام (أسرع طريق: Railway / Render / Fly.io / VPS)
1. ارفع هذا المجلد إلى GitHub.
2. أنشئ خدمة جديدة من المستودع (تلقائيًا من Dockerfile).
3. أضف **Volume دائم** مربوطًا بالمسار `/data` (وإلا ستضيع الحسابات والرسائل عند كل نشر).
4. متغيرات البيئة (اختيارية لكن موصى بها):
   - `JWT_SECRET` = نص عشوائي طويل
   - `TURN_URL`, `TURN_USER`, `TURN_PASS` = خادم TURN لضمان نجاح المكالمات خلف الشبكات المغلقة
5. اربط نطاقك (مثل chat.اسمك.com). HTTPS إلزامي لعمل المكالمات والتثبيت.

## ملاحظة مهمة
خادم واحد + SQLite يكفي لآلاف المستخدمين. للتوسع الأكبر: PostgreSQL + Redis + تخزين S3.
